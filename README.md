# Практична робота 1. Багатопотоковість в Java

**Предмет:** Асинхронне програмування
**Варіант 1:** Інтернет-замовлення
**Виконав:** Аніщенко Артем, група ТВ-43

## Опис

Симуляція роботи інтернет-магазину:

- адміністратор (потік) додає товари на сайт;
- покупці (потоки) заходять на сайт і купують товари;
- наявність товарів контролює семафор (`Semaphore`);
- магазин працює з 9:00 до 18:00, поза цим часом замовлення не приймаються;
- якщо товару немає в наявності, покупець чекає до 2 годин і йде ні з чим.

Час прискорений: 1 година магазину = 1 секунда.

Використано: `Thread`, інтерфейс `Runnable`, `Semaphore`, `synchronized`, `Thread.State`.

## Запуск

Потрібна Java JDK 8 або новіша.

```
cd src
javac -encoding UTF-8 OnlineShop.java
java OnlineShop
```

Якщо в консолі замість літер знаки питання: `java -Dstdout.encoding=UTF-8 OnlineShop`
